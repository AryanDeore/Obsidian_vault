#### Terms:
1. local: 
	1. The repo in the local machine
2. origin:
	1. Refers to the remote repo in git. ie the project on github.com.
	2. `git fetch origin` downloads information about all the branches from the remote repo. But it does not apply these changes.
		- fetch = just download the information
		- merge/rebase: apply the changes
3. HEAD: returns where you are working in current repo. There is only 1 HEAD per repo
   `git symbolic-ref HEAD`
4. rebase
5. squash
6. git pull= git fetch + git merge
#### Process of merging:
1. `git fetch origin`:
2. `git merge origin/main`:
3. `git merge origin/main` or `git rebase origin/main`:
4. `git push origin branch-name`:
5. `git rev-list --left-right --count main...HEAD`: Compare commit histories of main and current branch
