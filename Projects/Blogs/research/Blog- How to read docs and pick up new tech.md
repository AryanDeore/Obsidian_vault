The trick with documentation is that it's hard to find a mental place to meaningfully put lower level details until you understand the higher level details. You need to be able to see the tree as a whole, even if only vaguely, before you can know where an individual leaf goes.

Documentation is not a beginner resource. It's a mostly technical description of all the things a piece of code can do. It's typically ordered by sections and those sections are usually not related to each other. If you know what you're looking for, then documentation will usually give you the answer very quickly, but if you don't know what you need, you won't find the answer easily
