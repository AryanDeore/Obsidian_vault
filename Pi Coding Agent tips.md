### Evaluate Agents work
Ask yourself how you are going to evaluate the agent's work, and then tell the agent your evaluation criteria. 
**Evaluation Pack:** 
```txt
Record a video where, in place of a human, you demonstrate the different features to prove to me that it works.
Also attach screenshots of every step of the process. 
Show it to me as a single page HTML slide deck. 
```

### Exporting Session output as html
`/share`: share session as html
`/export`: export session as html

### Make the repo easy for agent to understand
```txt
Analyze the previous session. 
Find places where the agent went in the wrong direction, only to later figure out the correct way.
Make me some recommendations on what I could have added to the report that would have helped the agent reach its goal faster. 
```

### Jumping Timelines
 if you're unhappy with the agent's output, don't argue with it, saying that this is not how you wanted it, but instead make these changes because the context already polluted the incorrect output, which is weighing your context down. Instead, use the `/tree` command to go back into the conversational thread and modify your prompt to include what you want and steer the agent in right direction.
